# Jewellery ERP — সহজ নির্দেশিকা

> মেনুর নাম **মোটা অক্ষরে** লেখা আছে। মেনুগুলো বাঁদিকের Sidebar-এ পাবেন।

---

## ধাপ ১: শুরুতে একবার করুন

1. **Organisation**: দোকানের নাম, GSTIN, PAN, ঠিকানা আর লোগো দিন।
2. **Business settings → Jewellery**: কোন কোন সোনা বা রুপো (22K, 18K…) বিক্রি করেন, সেগুলো টিক দিন।
3. **Metal rates**: আজকের সোনা ও রুপোর দর দিন।
4. **Suppliers**: যাঁদের কাছ থেকে মাল কেনেন, তাঁদের যোগ করুন।
5. দোকানের মাল স্টকে তুলুন:
   - দোকানে আগে থেকে থাকা গহনা: **Products**-এ যোগ করুন, তারপর **Opening stock**-এ সেভ করুন।
   - নতুন কেনা মাল: **Purchases → New purchase**।
6. **Customers**: গ্রাহক যোগ করুন (নাম আর মোবাইলই যথেষ্ট)।

✅ এবার **New bill** থেকে বিক্রি শুরু করুন।

> একাধিক দোকান থাকলে **Branches**-এ শাখা যোগ করুন। Head Office আগে থেকেই তৈরি থাকে।

## ধাপ ২: প্রতিদিনের কাজ

| কখন | কী করবেন | কোথায় |
|---|---|---|
| সকালে | আজকের দর দিন (**না দিলে বিল হবে না**) | **Metal rates** |
| বিক্রির সময় | বারকোড স্ক্যান করুন → পেমেন্ট নিন → প্রিন্ট করুন | **New bill** |
| গ্রাহক কিছু বানাতে দিলে | অর্ডার নিন, অগ্রিম নিন | **Orders** |
| গ্রাহক পুরনো সোনা দিলে | বিলের মধ্যেই দিন, বা আলাদা কিনুন | **New bill** / **Old gold** |
| বাকি টাকা পেলে | গ্রাহকের পাতায় গিয়ে **Collect payment** | **Customers** |
| মাল কিনলে | সাপ্লায়ারের বিল লিখুন | **Purchases** |
| খরচ হলে | বিদ্যুৎ, ভাড়া ইত্যাদি লিখুন | **Expenses** |
| দিনের শেষে | হিসাব মিলিয়ে নিন | **Reports → Day book** |

## ধাপ ৩: মাসের শেষে

1. **Attendance**: কর্মচারীদের হাজিরা ঠিক আছে কিনা দেখুন। কেউ না এলে শুধু তাঁকে মার্ক করুন; বাকিরা নিজে থেকেই উপস্থিত ধরা হয়।
2. **Payroll**: Calculate → Review → Finalise → Pay (চারটে বোতাম পরপর চাপুন)।
3. **Profit & loss**: এই মাসে কত লাভ হলো দেখুন।
4. **Reports → GST summary**: GST-এর হিসাব দেখুন।

## কিছু আটকালে

| সমস্যা | সমাধান |
|---|---|
| বিল হচ্ছে না, দরের সমস্যা বলছে | **Metal rates**-এ আজকের দর দিন |

| নগদ সীমা পার বলছে | বাকি টাকা UPI, কার্ড বা ব্যাংকে নিন |
| PAN চাইছে | ₹২ লাখের বেশি বিলে PAN আছে এমন গ্রাহক বেছে নিন |
| কোনো মেনু দেখা যাচ্ছে না | আপনার রোলে অনুমতি নেই, **Roles & permissions**-এ দিন |
